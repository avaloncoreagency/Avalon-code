## 6. Hallazgos concretos de producto

**DEV Bridge:** `src/lib/dev-bridge/core.ts` produce avisos por cada par de PR con archivos superpuestos o bases distintas; 67 PR son hasta 2.211 pares. Esta rama agrupa los avisos de correlación cuando hay >20 PRs, pero mantiene fallos CI y conflictos confirmados por separado. Es mitigación visual, no reparación de permisos ni verificación de conectividad. Los comandos disponibles son `npm run bridge:doctor`, `bridge:sync`, `bridge:status`, `bridge:check`, `bridge:test`, `bridge:brief -- --read-only`. El modo público sin token es limitado y no debe afirmar CI o mergeabilidad.

**Oficina:** ya existe la ruta `/admin/workspace/crm/office/hq` con redirección desde `/office`. Esta rama muestra equipo, presencia, tareas y proyectos en la vista principal; no monta el panel ejecutivo de motores, ni el panel de ejecuciones de managers. El directorio virtual sigue disponible en un desplegable para no destruir funcionalidades. Las estaciones del escenario 3D aún existen y no se alteran los motores.

**Uso de IA:** `src/components/crm/overview.tsx` y `src/lib/crm/usage-units.ts` ya gestionan **capturas manuales** de Codex, Claude e Higgsfield. Esta rama añade barras de progreso solo cuando existe un límite reportado y evita inventar datos. La conexión autenticada de Higgsfield dentro de ChatGPT devolvió **1.903,75 créditos** el 2026-11-13, pero **esa conexión no está instalada en el runtime de Next.js**; el CRM no debe decir que es saldo automático sin backend autorizado. Para ChatGPT y Claude, no confundir uso API con cuotas de suscripción.
